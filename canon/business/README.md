# Business Skills

**Strategy skills for the business canon.**

These skills encode the strategic thinking of masters who have shaped how we understand competition, management, and organizational success.

## Available Skills

| Skill | Master | Source Material | Core Idea |
|-------|--------|-----------------|-----------|
| [horowitz/](horowitz/) | Ben Horowitz | The Hard Thing About Hard Things | Wartime leadership, lead bullets |
| [grove/](grove/) | Andy Grove | High Output Management | OKRs, managerial leverage, 10x forces |
| [helmer/](helmer/) | Hamilton Helmer | 7 Powers | Durable competitive advantage, moats |
| [porter/](porter/) | Michael Porter | Competitive Strategy | Five forces, generic strategies, trade-offs |
| [rumelt/](rumelt/) | Richard Rumelt | Good Strategy Bad Strategy | Diagnosis, guiding policy, coherent action |

## When to Use What

| Situation | Skill |
|-----------|-------|
| Evaluating competitive position | `porter` (five forces, value chain) |
| Analyzing business moats | `helmer` (7 powers) |
| Developing/reviewing strategy | `rumelt` (good vs bad strategy) |
| Managing teams, setting OKRs | `grove` (high output management) |
| Navigating crisis, hard decisions | `horowitz` (wartime CEO) |
| Facing industry disruption | `grove` (strategic inflection points) |
| Building company culture | `horowitz` (what you do is who you are) |

## The Strategy Stack

These skills complement each other:

```
┌─────────────────────────────────────────────┐
│  RUMELT: Is this good strategy?             │  ← Quality check
│  (Diagnosis → Policy → Action)              │
├─────────────────────────────────────────────┤
│  HELMER: What powers do we have/need?       │  ← Moat analysis
│  (7 Powers framework)                       │
├─────────────────────────────────────────────┤
│  PORTER: What's our competitive position?   │  ← Industry structure
│  (Five forces, generic strategies)          │
├─────────────────────────────────────────────┤
│  GROVE: How do we execute and manage?       │  ← Operations
│  (OKRs, leverage, one-on-ones)              │
├─────────────────────────────────────────────┤
│  HOROWITZ: How do we lead through crisis?   │  ← Leadership
│  (Wartime/peacetime, hard things)           │
└─────────────────────────────────────────────┘
```
