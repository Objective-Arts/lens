# Canon Skills

**You can't Skill what you've never heard of.**

This repo makes the canon Skillable.

## What This Is

Skills that encode the published wisdom of software's masters. Not vibes. Not interpretations. Principles drawn from their books, talks, code, and documented thinking.

## Why This Exists

Claude Code lets you invoke expertise on demand. But whose expertise?

Most Skills encode *your* procedural knowledge. This repo asks: **why would you want yours when you could have theirs?**

## How to Use

1. Clone this repo
2. Register with Claude Code: `/skill add /path/to/canon-skills`
3. Invoke by name: "Apply Kernighan principles to this code"

Or just read them. The wisdom stands alone.

## Contributing

To add a master:

1. Create a folder with their name
2. Write a `SKILL.md` based on their **published, attributable work**
3. Cite sources
4. Submit a PR

No vibes. No interpretations. If you can't cite it, don't include it.
