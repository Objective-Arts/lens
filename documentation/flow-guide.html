Which Flow Do I Use?

A simple decision tree to choose the right path.

Is there existing code?
NO → New Code Flow
/plan → /structure-first → /implement
YES → Is it working correctly?
YES, but messy → Legacy Code Flow (refactor)
/plan → /structure-first → /refactor-check
NO, has bugs → Fix first, then decide
Bug fixes don't need full workflow

Same skills, different canon. The workflow adapts to your starting point.

New Code: Build Forward

  • • Start with requirements (PRD)
  • • Design types before implementation
  • • Build incrementally from plan
  • • Canon: architecture & language masters

Legacy Code: Understand First

  • • Start with existing code
  • • Find seams for safe changes
  • • Characterize before changing
  • • Canon: Feathers, Fowler, refactoring masters
