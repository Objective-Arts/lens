Claude Optimal

A Configuration Methodology for Production-Quality Claude Code

The Problem

Claude produces working code that fails expert review: 150-line functions, mixed concerns, inconsistent patterns

Claude knows best practices. It just doesn't apply them unless explicitly required.

Quality is Generative, Not Corrective

Build quality in from the start. By the time code reaches external review, it should already be clean.

The final hook is confirmatory. It validates what's already right.

Additive, Not Adversarial

You're not fighting Claude or constraining it. You're giving Claude the expertise and context to do it right from the start.

Add lenses, not rules. Quality emerges from context you provide.

Patterns: Configuration → Workflow

Patterns are configured once, then shape how Claude works. You don't "use" them - they're the environment.

Canon Factory

CONFIGURED:
profile: base-tech + javascript + react
WORKFLOW:

React code automatically follows Abramov's mental model - hooks patterns, composition. It's the lens, not a tool you invoke.

Structure-First

CONFIGURED:
New features → require --structure-first
WORKFLOW:

"Build dashboard" → Claude shows architecture plan with components and data flow. Waits for approval before implementing.

Skill Observer (Auto-Invoke)

CONFIGURED:
auth|login|password → /security-mindset
WORKFLOW:

"Add password reset" → Security skill auto-activates. Code has validation, rate limiting, secure tokens without being asked.

Quality Template

CONFIGURED:
sequence: test → review → security
WORKFLOW:

"--review-hard" → Agents run in sequence: test-engineer, code-reviewer, then security-auditor. Combined report.

Hook Chain

CONFIGURED:
pre-push: [test, lint, security-scan]
WORKFLOW:

"push" → Hooks run in sequence. All must pass. Confirmatory only - quality was built in.

Domain Lens

CONFIGURED:
canon.domain: bloch (Java project)
WORKFLOW:

"Add a builder for UserConfig" → Writes Effective Java Item 2 pattern. Private constructor, fluent API, validation. Automatic.

Key Insight: Patterns are configured once, then they're just how Claude works in that project.

The Meta-Pattern: Compound Quality

Individual patterns add value linearly. Combined patterns multiply value.

Canon (1.3x) x Quality Sequence (1.2x) x Security (1.2x) x Parallel (2x)
= 3.7x Effective Development

Not additive (1.3 + 1.2 + 1.2 + 2.0 = 5.7), but multiplicative (1.3 x 1.2 x 1.2 x 2.0 = 3.7)
