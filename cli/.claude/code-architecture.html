CLI Code Architecture

cc-config and Ralph implementation structure

Entry Points

src/cli/index.ts
Main CLI entry. Registers all command groups with Commander.js.
cc-config <command>
src/cli/commands/
Command implementations: profile, canon, workflow, mcp, scan, tools, hooks, trace
src/ralph/index.ts
Ralph entry. Exports run() for PRD processing.
ralph <prd-file>

Core Orchestration

runner.ts
Main loop: parse PRD, iterate items, run phases, handle retries, generate summary.
run() processItem() executePhase()
types.ts
Core types: PrdItem, Session, PhaseName, PhaseResult, RalphConfig
process/claude.ts
Spawn Claude CLI, stream JSON output, parse tool events.
runClaude() StreamCallbacks

Phase Implementations

phases/types.ts
Phase interface, BasePhase class, PhaseContext, PhaseResult
phases/*.ts
8 phases: plan, structure-first, implement, refactor-check, test, doc-code
adversarial-review.ts
MCP phase: calls Gemini via mcp__gemini-reviewer
static-analysis.ts
MCP phase: calls Qodana via mcp__qodana

Support Modules

prd/
PRD parsing and updating: parser.ts, updater.ts
display/
Terminal output: terminal.ts (Spinner), phase-output.ts
summary/
HTML summary generation: collector.ts, generator.ts
parsers/
Output parsing: claude-stream.ts, gemini.ts, qodana.ts
skills/
Skill loading from .claude/skills/
config/
Load ralph-config.yaml

Self-Correction Retry Loop

Correctable Failures (up to 3 retries)

  • issues not fixed
  • function is N lines (max 30)
  • vague names / vague language
  • missing sections
  • tests failed / not run
  • ISSUES_REMAINING > 0

Retry Flow

1. Phase fails validation
2. isCorrectableFailure() → true
3. buildCorrectivePrompt(error)
4. Re-run phase with correction
5. Repeat up to MAX_RETRIES (3)
