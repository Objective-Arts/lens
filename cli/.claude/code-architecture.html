cc-config CLI
TypeScript • src/cli/, src/profiles/, src/canon/
Configuration management. Installs skills, applies profiles, manages MCP servers.

$ cc-config canon install kernighan
$ cc-config workflow status

Ralph Loop
TypeScript • src/ralph/
Autonomous PRD processing. Runs 8 phases per item, loads skills as expert guidance.
$ ralph prd.md
$ ralph --resume prd.md
$ ralph --skip-review prd.md

What Each Layer Does

Workflow Skills

What: Markdown files with instructions for Claude

Where: .claude/skills/*/SKILL.md

Purpose: When user types /implement, Claude reads the skill file and follows the instructions. The skill tells Claude what to do, what output format to use, which experts to apply.

Documentation: Skills ARE documentation. No separate tech docs needed.

cc-config CLI

What: TypeScript CLI tool

Where: src/cli/, src/profiles/, src/canon/, src/workflow/

Purpose: Sets up projects with the right skills. Composes profiles, copies canon skills, configures MCP servers, generates CLAUDE.md.

Documentation: Needs code-level docs (this page).

Ralph Loop

What: TypeScript autonomous runner

Where: src/ralph/

Purpose: Given a PRD file, processes each item through 8 phases automatically. Spawns Claude with prompts, parses output, handles retries, generates summary.

Documentation: Needs code-level docs (this page).

Self-Correction Retry Loop

phase.execute()
→
FAILED: "3 issues not fixed"
→
isCorrectableFailure()?
YES:
buildCorrectivePrompt()
→
context.correctivePrompt = "..."
→
phase.execute() (retry)
Max 3 retries. Correctable patterns: /issues not fixed/ | /function.*lines.*max/ | /tests.*failed/ | /UNFIXED.*[1-9]/
