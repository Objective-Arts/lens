### 4. **ralph/phases/production-readiness.ts:357** — File exceeds 300-line limit
- Problem: 357 lines with execute() spanning 123 lines
- Impact: Single function too large to hold in one's head
- Suggestion: Split execute() into auditStep() and fixStep()

### 5. **ralph/phases/loader.ts:335** — File exceeds 300-line limit
- Problem: 335 lines with embedded default config
- Impact: Config and loading logic mixed
- Suggestion: Move default phase config to YAML file

### 6. **mcp/registry.ts:40,142** — Path injection in server registry
- Problem: `server.name` used directly in filename construction without validation
- Impact: Server name like `"../../../etc/passwd"` could write to arbitrary paths
- Suggestion: Validate server name with allowlist `[a-z0-9-]` before file operations

### 7. **hooks/index.ts:65** — Shell injection in workflow marker command
- Problem: Unescaped shell variables and paths in WORKFLOW_MARKER_COMMAND
- Impact: Paths with spaces or special chars could cause command injection
- Suggestion: Use `[ -f "$marker" ]` with proper quoting

### 8. **ralph/summary/generator.ts:36** — XSS in HTML generation
- Problem: JSON embedded in script tag escapes `</` but doesn't fully HTML-encode
- Impact: Malicious input in summary strings could break out of script context
- Suggestion: Use proper HTML escaping library or embed as data attributes

### 9. **canon/operations.ts:95** — Path traversal not fully validated
- Problem: `path.relative()` can return `..` sequences if source is outside canon path
- Impact: Could allow reading/writing outside intended directory
- Suggestion: Validate `!relative.startsWith('..')`

### 10. **profiles/apply.ts:346** — Substring matching for profile detection
- Problem: `profile.name?.includes('ralph-integration')` matches any profile containing that substring
- Impact: Profile named `"my-ralph-integration-test"` incorrectly triggers MCP setup
- Suggestion: Use exact match or enum

### 11. **ralph/process/claude.ts:49** — Shell injection in spawn args
- Problem: `allowedTools.join(',')` used directly as command-line argument without validation
- Impact: Tool names with shell metacharacters could execute arbitrary commands
- Suggestion: Validate tool names match `/^[a-z_-]+$/i`

### 12. **mcp/operations.ts:225-231** — Silent empty string substitution for missing env vars
- Problem: `resolveEnvVars()` returns empty string for missing environment variables
- Impact: Servers may receive empty credentials and fail silently or bypass auth
- Suggestion: Return null/undefined or throw on missing required env vars
